# Local Apps

## How do I install these formulae?

`brew install local/apps/<formula>`

Or `brew tap local/apps` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "local/apps"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
